# Implementation Plan: Generator UI & Retro Pixel Art Experience

**Branch**: `002-generator-ui` | **Date**: 2026-02-22 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/002-generator-ui/spec.md`

## Summary

Redesign the minecraft-skin-gen UI to deliver a bold, arcade-inspired retro pixel art experience that matches the Minecraft brand identity. The existing backend (Supabase, Stripe, Gemini) is untouched — all changes are frontend-only. The plan delivers: (1) an arcade dark colour theme replacing the generic shadcn default, (2) a pixel heading font (Press Start 2P), (3) a redesigned landing page, (4) style preset chips for the generator form, (5) a reference image thumbnail, and (6) polished layouts for the generator page, credit counter, and upgrade prompt.

## Implementation Phases

### Phase 1: Design System Foundation
*Establishes the retro arcade visual identity. All later phases depend on this.*

**1.1 — CSS Token Palette**
Replace `globals.css` `:root` and `.dark` custom properties with the arcade dark palette from `research.md`. Add `.pixel-art { image-rendering: pixelated; image-rendering: crisp-edges; }` utility class. Keep all token names identical (no shadcn component changes needed).

**1.2 — Pixel Font**
In `layout.tsx`: import `Press_Start_2P` from `next/font/google` with `weight: '400'`, `subsets: ['latin']`, `display: 'swap'`. Expose as CSS variable `--font-pixel`. Add `class="dark"` to `<html>` to force dark mode globally.

**1.3 — Tailwind Extension**
In `tailwind.config.ts`: extend `theme.extend.fontFamily` with `pixel: ['var(--font-pixel)', 'monospace']`. This enables `font-pixel` utility class in all components.

**Tests**: Render `layout.tsx` in jsdom and assert `<html>` has `class="dark"` and the `--font-pixel` variable is defined.

### Phase 2: Landing Page Redesign
*Depends on Phase 1 (needs arcade palette + pixel font tokens).*

**2.1 — Hero Section**
Replace `app/page.tsx` with a redesigned static page:
- Full-viewport dark hero (`min-h-screen bg-background`)
- `<h1>` using `font-pixel` class with Minecraft Skin Generator name
- One-sentence value proposition in `text-foreground`

Simple two-column comparison: Free (3/day) vs Pro (50/day, no ads, priority). Uses `bg-secondary` to stand out.

**Tests**: Render `page.tsx` and assert: `<h1>` present, three feature cards visible, "Sign Up Free" link href is `/signup`, "Log In" link href is `/login`.

### Phase 3: StylePresets Component (New)
*Depends on Phase 1 (needs palette tokens for chip active states).*

**3.1 — Component**
Create `components/skin-generator/StylePresets.tsx`:
- `PRESETS` constant array (6 entries from research.md)
- `activeIds` state (`Set<string>`)
- Toggle handler: add/remove ID from set, compute combined keywords, call `onPresetsChange`
- Renders a flex-wrapped row of `<button>` elements with `aria-pressed` attribute
- Active chips: `bg-primary text-primary-foreground` variant
- Inactive chips: `bg-secondary text-secondary-foreground hover:bg-secondary/80`

**3.2 — Integration**
In `GeneratorPageClient.tsx`:
- Add `const [presetKeywords, setPresetKeywords] = useState('')`
- Render `<StylePresets onPresetsChange={setPresetKeywords} disabled={isExhausted || isGenerating} />` above `<GeneratorForm>`
- Pass `presetKeywords` to `<GeneratorForm>`

**Tests**:
- `StylePresets`: clicking chip toggles `aria-pressed`; combined keywords string matches selected presets; clicking active chip removes its keywords; `disabled` prop makes chips non-interactive.

### Phase 4: GeneratorForm Enhancements
*Depends on Phase 3 (receives `presetKeywords` prop).*

**4.1 — presetKeywords Prop**
Add `presetKeywords?: string` to `GeneratorFormProps`. In `handleSubmit`, construct:
```typescript
const base = prompt.trim()
const finalPrompt = presetKeywords
  ? `${presetKeywords}${base ? `. ${base}` : ''}`
  : base
```
Pass `finalPrompt` (not `prompt`) to the FormData append.

**4.2 — Image Thumbnail Preview**
In `handleFileChange`, after validation passes:
```typescript
const objectUrl = URL.createObjectURL(file)
setThumbnailUrl(objectUrl)
```
In `clearFile`, revoke the URL: `URL.revokeObjectURL(thumbnailUrl)`.
Add `<img src={thumbnailUrl} alt="Reference image preview" className="h-12 w-12 rounded object-cover pixel-art" />` next to the remove button when `referenceFile` is set.

**4.3 — Placeholder Copy**
Update placeholder to: `"e.g. retro knight in red armor, cyberpunk hacker with neon visor, 90s arcade fighter…"`

**Tests**:
- `presetKeywords` prepended correctly when non-empty.
- `presetKeywords` alone (empty prompt) produces valid `finalPrompt`.
- Image thumbnail renders when file is selected; revokes URL on clear.
